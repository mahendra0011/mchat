# Minimum Client Policy

## Minimum Required Client Version for Security Updates

All clients must be on at least the following minimum versions to receive security updates and continue functioning:

| Platform | Minimum Version | Release Date |
|----------|----------------|--------------|
| Web App | 1.0.0 | 2024-01-15 |
| iOS | 2.1.0 | 2024-06-01 |
| Android | 2.0.0 | 2024-06-15 |

## End-of-Life Dates for Old Clients

| Client | EOL Date | Action After EOL |
|--------|----------|------------------|
| Chrome 107 | 2026-03-01 | Must upgrade to Chrome 108+ |
| Firefox 101 | 2026-03-01 | Must upgrade to Firefox 102+ |
| Android < 10 | 2026-09-01 | Must upgrade to Android 12+ |
| iOS < 15 | 2026-03-01 | Must upgrade to iOS 15+ |

## Feature Compatibility Matrix

| Feature | Minimum Client Version | Notes |
|---------|----------------------|-------|
| Link Previews | 1.0.0 | — |
| E2EE Search | 1.2.0 | Requires client-side crypto |
| Realtime Calls | 1.5.0 | WebSocket based |
| Message Virtualization | 2.0.0 | Infinite scroll for messages |
| Group Governance | 1.1.0 | Role-based permissions |
